# AI Assistant Documentation (AGENTS.md)

## Selected AI Assistant
- **Assistant:** Antigravity (Google DeepMind)
- **Role:** Autonomous Pair-Programming & Coding Assistant

## Selection Rationale
As discussed in Week 01 ("Decide first. Code later."):
1. **Cost Efficiency:** Antigravity is accessible without prohibitive subscription barriers compared to commercial alternatives.
2. **Context-Aware Coding:** Possesses comprehensive tooling for terminal operations, file modifications, git versioning, and project orchestration.
3. **Containerized Workflow Support:** Assists directly in structuring reproducible Docker Compose setups and service configurations.

## How Antigravity is Utilized
- **Architecture & Scaffolding:** Guiding directory structure, Docker environment setup, and database orchestration.
- **Routing & Backend Logic:** Assisting in creating efficient request routers and endpoint handlers in PHP.
- **Verification & Debugging:** Verifying container readiness, route parsing, and running automated/manual checks.
- **Documentation:** Keeping README and project logs synchronized with classroom requirements.
